- `join.html` — оқушы беті (планшет, міндетті емес); `join.html?g=1` — қонақтар
- `jumys-paraq.html` — А, В, С деңгейлі жұмыс парақтары
- `materialdar/` — ҚМЖ және жұмыс парақтары (Word, PDF)
